# Menu MBG — GitHub Pages

Versi ini dibuat lebih mendekati gambar referensi:
- Mobile-first dengan lebar maksimal 480px.
- Header biru.
- Posisi logo dan identitas SPPG di bagian atas.
- Judul hari dan tanggal.
- Garis aksen kuning.
- Foto menu besar dengan kartu putih.
- Hanya fokus pada **tampilan menu MBG**.

## Upload ke GitHub

Upload seluruh isi folder ke repository, lalu:

**Settings → Pages → Deploy from a branch → main → / (root)**

Pastikan `index.html` berada di root repository.
